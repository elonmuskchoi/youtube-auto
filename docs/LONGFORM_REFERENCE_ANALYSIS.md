## 공통 구조

1. **결과를 먼저 보여준다.** 첫 5초에 결과 화면 또는 핵심 반전 문장을 배치한다.
2. **기존 상식을 뒤집는다.** “AI 음악 한 곡이 돈을 버는 것이 아니다”처럼 잘못된 기대를 즉시 정정한다.
3. **증거 약속을 한다.** 공개 채널 사례, 실제 화면, 수강생 자료를 언제 보여줄지 미리 말한다.
4. **주장-화면-원리 순서로 설명한다.** 대본의 한 주장마다 해당 UI나 근거 화면을 정확히 붙인다.
5. **반론을 선제 처리한다.** 저작권, 포화, 수익 편차, 자동화의 한계를 중간에 설명한다.
6. **CTA는 두 번만 사용한다.** 초반에는 기대감, 마지막에는 A-Z 자료와 다음 행동을 안내한다.

## 적용 썸네일 문구

- 메인: `음악 몰라도 됩니다`
- 보조: `AI 플리 자동화`
- 근거 배지: `실제 채널·수강생 사례`

수익 금액을 보장하는 표현은 쓰지 않는다. 공개 채널의 추정 수익은 반드시 `추정치`로 표시한다.

## 적용 초반 후킹 (0–30초)

> 음악을 한 곡도 만들 줄 모르는 사람이 AI로 플레이리스트 채널을 운영할 수 있을까요? 결론부터 말씀드리면 가능합니다. 하지만 AI로 음악 한 곡 뽑는다고 돈이 생기는 건 아닙니다. 실제로 조회수를 만든 공개 채널과 수강생 운영 자료를 비교해보니, 결과를 가른 건 음악 실력이 아니라 사람들이 오래 듣는 상황을 고르고 곡, 커버, 제목, 긴 영상을 같은 기준으로 반복하는 시스템이었습니다. 오늘 그 구조를 실제 화면으로 보여드리겠습니다. 마지막에는 그대로 따라 할 수 있는 A-Z 가이드도 정리해드리겠습니다.

## 화면·자막·효과음 적용

- 0–3초: 스튜디오 결과 화면 빠른 공개 + 짧은 임팩트
- 3–8초: 핵심 문구 두 줄씩 강조, 단어 단위 팝업 금지
- 8–18초: 공개 채널/자료 카드 2–3개를 빠르게 예고
- 18–30초: `음악 실력 X → 반복 시스템 O` 비교 그래픽
- 자막: 실제 음성 그대로, 음성 타이밍 기준, 1–2행 유지
- 전환음: 화면 전환에만 짧게 사용하고 내레이션보다 8–14 dB 낮게 믹싱
