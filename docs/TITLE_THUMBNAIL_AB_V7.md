# V7 제목·썸네일 A/B 후보

## A안 — 쉬운 시작 강조

- 제목: `음악을 몰라도 AI 플레이리스트 채널을 운영할 수 있는 이유`
- 썸네일: `음악 몰라도 / 됩니다`
- 기대 효과: 초보자 유입과 시작 장벽 완화

## B안 — 반전과 검증 강조

- 제목: `AI 음악 한 곡으로는 수익화가 안 됩니다｜실제 채널에서 확인한 구조`
- 썸네일: `AI 음악 한 곡으론 / 안 됩니다`
- 기대 효과: 기존 기대를 뒤집어 클릭 유도, 사례·검증 구간과 연결

## C안 — 시스템 강조

- 제목: `조회수 나오는 AI 플레이리스트는 음악보다 이것이 달랐습니다`
- 권장 썸네일 보조문구: `반복 시스템의 차이`
- 기대 효과: 결과의 원인을 알고 싶은 시청자에게 적합

업로드 후 24~72시간의 클릭률과 첫 30초 유지율을 비교한다. 제목만 바꿀 때는 썸네일을 유지하고, 썸네일을 바꿀 때는 제목을 유지해 변수를 한 번에 하나만 테스트한다.
