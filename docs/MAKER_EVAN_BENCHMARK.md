# Maker Evan 벤치마크 적용 기록 (2026-08-14)

채널: https://www.youtube.com/@maker-evan/videos

분석 목적은 고유 문구나 그래픽을 복제하는 것이 아니라 정보형 AI 영상의 가독성·리듬·전달 순서를 개선하는 것이다.

## 확인한 공개 패턴

- 채널은 약 3.9만 구독자, 221개 영상 규모로 확인했다.
- 제목은 `기존 행동을 부정하는 문장 → 새 방식` 또는 `시간·비용의 구체적 차이 → 결과` 구조가 많다.
  - 예: 편집 프로그램을 지웠지만 영상은 더 빨리 나온다는 대비
  - 예: 40분 걸린 일을 자동화로 끝냈다는 결과 선공개
- 영상 도입은 장식보다 결론 문장 한 개를 크게 보여주는 편집을 사용한다.
- 흰색/단색 배경, 넓은 여백, 굵은 검정 글자, 짧은 비교선 등 최소 요소로 개념을 설명한다.
- 자막은 영상 하단의 짙은 캡슐 안에 분리해 배경과 상관없이 읽히게 한다.
- 실제 도구 화면은 설명이 필요한 순간에만 보여주고, 핵심 주장 구간에서는 개념 카드로 시선을 정리한다.

## 이번 영상에 적용한 항목

1. 후킹을 `AI 음악 한 곡이 돈을 만드는 것은 아니다`라는 반전으로 시작한다.
2. CTA의 금색 테두리, 가짜 버튼, 작은 보조문구, 장식 커서를 제거한다.
3. CTA 첫 장면은 오프화이트 배경과 세 개의 자료 카드만 사용한다.
4. CTA 마지막 장면은 `고정댓글에서 무료 자료 확인`이라는 행동 하나만 강조한다.
5. 자막을 Pretendard SemiBold와 반투명 다크 캡슐로 변경한다.
6. BGM과 효과음은 립싱크 완료 후 마지막 오디오 패스에만 적용한다.

## 다음 단계에서 더 고도화할 항목

- 모든 주장에 `핵심 문장 카드 → 실제 화면 → 결과 요약` 3단 구조 적용
- 20~35초마다 개념 카드 또는 실제 조작 화면으로 시각 리셋
- 마우스 위치를 따라가는 확대 대신 클릭 대상만 짧게 하이라이트
- 공개 사례 카드에 채널명, 조회수, 추정치 기준일을 같은 위치에 고정
- 영상별 제목 3안과 썸네일 2안을 제작해 업로드 전 A/B 후보로 보관
- 장면별 체류시간과 이탈 구간을 다음 영상 타임라인에 반영

수익 숫자는 보장 표현으로 사용하지 않으며, 외부 도구 값은 반드시 추정치라고 표시한다.
