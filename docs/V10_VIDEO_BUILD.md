# V10 플레이리스트 롱폼 제작 기준

V10은 성공 가능성과 “나도 시작할 수 있다”는 감정을 유지하는 약 5분 롱폼 버전이다.

## 제작 순서

1. 승인된 대본으로 Typecast 필재 음성과 단어 타이밍을 만든다.
2. 완성된 음성 파일을 HeyGen AI빌더 아바타에 입력한다. 텍스트 음성을 다시 만들지 않는다.
3. 일반 Avatar III 엔진을 요청하고 결과 영상을 원형으로 잘라 우측 하단에 고정한다.
4. 단어 타이밍 기준으로 대본과 동일한 자막을 합성한다.
5. 메인 웹 화면, 동적 스크롤, 공개 사례, 수강생 사례, CTA 영상 자료를 대사 의미에 맞춰 배치한다.
6. 완성된 립싱크 영상 위에 BGM과 효과음을 마지막 단계에서 믹스한다.

재현에 필요한 비밀값은 환경변수로만 공급한다. 저장소의 설정 파일에는 키를 기록하지 않는다.

실행 입력과 출력 경로는 `config/final-v10-inputs.json`에 기록되어 있다.
